 # 📚 StudySync - Smart Study Dashboard

StudySync is a full-stack study dashboard built with **React**, **Tailwind CSS**, and **Node.js/Express**, designed to help students stay focused, track their goals, and monitor study time efficiently.

---

## 🌟 Features

- 🎯 **Goal Setting**: Set and manage your study goals by subject.
- ⏱️ **Study Time Tracking**: Automatically calculates total study time across sessions.
- 🏅 **Achievements**: Earn badges like 🥉 Bronze (500+ mins) and 🥇 Gold (1000+ mins).
- 🌗 **Dark/Light Mode**: Toggle between light and dark themes.
- 📊 **Progress Overview**: View session logs and goal status visually.
- 🔐 **Authentication**: Secure login using JWT.
- 🧠 **Backend with MongoDB**: Stores user sessions, goals, and badges persistently.

---

## 🚀 Tech Stack

- **Frontend**: React, Tailwind CSS, React Icons
- **Backend**: Node.js, Express, MongoDB
- **Authentication**: JWT
- **Version Control**: Git & GitHub
